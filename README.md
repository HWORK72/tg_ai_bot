# tg_ai_bot
Бот-ИИ в телеграме
Простой бесплатный бот с интеграцией ИИ. Пишешь боту запрос, он через openroute отправляет тебе ответ через одну из нескольких бесплатных нейросетей. Интеграция идет через API, бот умеет запоминать чат, память хранится на оперативной памяти, была бы нужда в хайлоад проекте - сделал бы через базу данных, но целью было научиться работать с интеграцией ИИ, поскольку проект бесплатный - подключить флагманские модели не вышло, всё это требует хотя бы для начала деплоя на незаблокированном регионе. Бота нужно деплойить через Botfather указывать данные в .env файле
